# Мастеринг трека #1 для Offstep / Стриминговых площадок

## 1. Технические характеристики готовых WAV:
- **Частота дискретизации**: `44.1 kHz` (стандарт стриминга Offstep / Spotify / Apple Music / Яндекс Музыка / VK Музыка)
- **Битность**: `24-bit PCM` (максимальное студийное качество без потерь) + `16-bit PCM` версия
- **Каналы**: `Stereo`
- **True Peak**: `-1.0 dBFS` (гарантирует отсутствие межсэмплового клиппинга при перекодировании в AAC/MP3 на площадках)
- **Интегрированная громкость (Integrated LUFS)**: `-10.0 LUFS` (плотный, пробивной коммерческий уровень для хип-хопа и бум-бэпа)

## 2. Что было сделано при мастеринге:
1. **Устранение клиппинга исходника**:
   - В оригинальном MP3 True Peak достигал `+1.0 dBFS` (цифровой перегруз).
   - Все пики взяты под контроль прецизионным лимитером с lookahead на уровне `-1.0 dBTP`.
2. **Очистка суб-низа**:
   - Срезан паразитный инфразвуковой гул ниже 28 Гц (DC-офсет и сабсоник-мусор, забивавший хэдрум).
3. **Плотность и вес бочки / баса**:
   - Аккуратный акцент в районе 60–62 Гц для плотного удара в грудь.
4. **Устранение коробочного резонанса**:
   - Точечный вырез в нижней середине на 330 Гц (убрана мутность и гулкость).
5. **Читаемость и агрессия вокала**:
   - Подъем презенса на 3.6 кГц — читка и рабочий барабан (снейр) стали острее и отчетливее.
6. **Воздух и детализация**:
   - Шельфовое осветление выше 11.5 кГц — хай-хэты и воздух зазвучали чисто без резкости.
7. **Стерео-баланс и фазовая совместимость**:
   - Низкие частоты (бас и бочка) строго центрированы в моно.
   - Подготовлена стерео-расширенная версия для глубокого звучания в наушниках и мониторах, а также direct-версия с оригинальным панорамированием.
